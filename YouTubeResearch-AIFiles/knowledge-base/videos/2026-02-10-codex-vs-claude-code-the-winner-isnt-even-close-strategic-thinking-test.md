## Strategic Patterns Identified

### Pattern 1: **Planning-as-Leverage Arbitrage**
In domains with execution commoditization (AI can code, write, analyze), strategic value shifts to **decision architecture**—the frameworks that determine what to execute. Tools that help you decide better create more value than tools that execute faster. This is a market inefficiency: most AI tools optimize for execution speed, under-investing in planning capacity.

### Pattern 2: **Interface-Perception Trap**
Powerful capabilities can be inaccessible not due to complexity but due to **perception barriers**. Command-line interfaces scare non-technical users away from tools that would create most value for them. Marketing/positioning creates artificial market segmentation that obscures actual value distribution. The solution: education + interface abstraction.

### Pattern 3: **Strategic Altitude Matching**
Different decision types require different abstraction levels. Strategic decisions require **staying at high altitude** (options, trade-offs, questions) while tactical decisions require specificity (steps, details, implementation). Tools optimized for one altitude perform poorly at the other. The key skill is recognizing which altitude your decision requires and selecting/prompting tools accordingly.
