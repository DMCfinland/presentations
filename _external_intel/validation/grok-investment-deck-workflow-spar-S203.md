# Grok Expert Kill Vector Analysis — Investment Deck Workflow (S203)

## Verdict

"80% teknisesti siisti, mutta rakennettu väärälle perustalle. Workflow on oikeudellinen pommi EU:ssa/Suomessa ja kumoaa itsensä HNWI-ostajan silmissä."

Tappavat kill vectorit:
1. Legal/compliance-räjähdys (Timeshare + AIFMD)
2. Uskottavuuden menetys suomalaiselle HNWI:lle (liian aspirational)
3. Toistuvat rebuildit koska Phase 0 ei lukitse tarpeeksi
4. Väärä ostajapsykologia (aspiration first väärin Suomessa)
5. Liian optimistinen aikataulu

## Q1 — Puuttuvat vaiheet

Ammattilainen tekisi aina nämä, workflow ei mainitse:

1. **Prospect-taustatutkimus + KYC/AML-esitarkistus** (Phase 0 jälkeen heti). Onko hän qualifying investor? Family office-neuvonantaja?
2. **Kilpailija-analyysi** (pakollinen Subagent C Phase 1:een). Muut fractional-tarjoukset Skandinaviassa? Hinnoittelu, exit-ehdot, track record?
3. **Compliance-tarkistus lakimiehellä ENNEN buildia.** Onko rakenne timeshare? AIF? Tarvitaanko KID/PRIIPs? EU Timeshare Directive 2008/122/EC.
4. **Ostajan veroprofilointi** (Phase 0 laajennettuna). ALV-palautus, EVL-poistot, myyntivoittovero.
5. **Riippumaton talousmallin audit** (kirjanpitäjä/CFA, ei vain Gemini).
6. **Valmis syndicate agreement / exit-malli Phase 0:ssa.** Ostaja kysyy aina: "Miten pääsen ulos?"

## Q2 — Väärät oletukset

- **45-60 min aikataulu: Utopistinen.** Oikea lakimies + audit + lisenssit = 4-8h minimissään.
- **Kuvat saatavilla helposti:** Brokerage-sivut usein watermarkattuja tai maksullisia. WhatsApp-kuvat eivät riitä HNWI-tasolle.
- **"Anti-timeshare + disclaimer riittää": Väärin.** EU Timeshare Directive kattaa veneet ja loma-asunnot selkeästi. Markkinointi "returns/Bear/Base/Bull" = kiellettyä investointimarkkinointia Suomessa.
- **HNWI ostaa aspiration first: Väärin Skandinaviassa.** Suomalainen haluaa ensin faktat, riskit, verovaikutukset. Aspiration = lopuksi, ei aluksi.
- **Sama workflow kaikille asset classeille: Ei.** Veneessä crew/fuel/depreciation+VAT-charter kriittisiä. Loma-asunnossa kaavoitus+yhtiömuoto. Kiinteistösyndikaatissa AIF-riski.

## Q3 — Phase 0 LOCK — Puuttuvat kysymykset

**Kriittisin puuttuva kysymys (useimmiten muuttaa suunnan):**
"Mikä on tarkka juridinen rakenne (co-ownership / SPV / AIF / muu) ja onko se tarkastettu suomalaisen merioikeuden / finanssioikeuden lakimiehen toimesta Timeshare Directive- ja AIFMD-näkökulmasta?"

Red flags → älä rakenna:
- Juridinen rakenne epämääräinen tai "sovitaan myöhemmin"
- Kulut/hinnat muuttuvat vielä
- Ei nimettyä management companya + referenssejä
- Ostaja ei ole vielä vahvistettu
- Verovaikutuksia ei ole vahvistettu

## Q4 — Spar-kysymykset

Puuttuu:
- **Compliance-subagent** (lakimiehen profiili): Timeshare Directive + AIFMD-tarkistus
- **Verosubagentti:** ALV-palautus, EVL-poistot, myyntivoittovero
- Grok-profiiliin lisättävä: "Finnish HNWI family office advisor, 55v, verotietoinen, nähnyt 20 fractional-dealia"
- Gemini-kyselyyn lisättävä: "[asset] fractional ownership compliance Timeshare Directive Finland EU"

## Q5 — Nordic HNWI psykologia

**Ei ole kuvattu oikein.** Suomalainen vs. muut markkinat:
- Erittäin skeptinen ylilupauksia kohtaan
- Läpinäkyvyys edellä: haluaa nähdä oikean tappion Bear-casessa, crew-kulut, depreciation ja verot
- ESG + kestävyys iso tekijä
- Verotus kunniakysymys — ei statusleikkiä kuten USA:ssa
- Haluaa **faktat ensin**, ei aspiration

**Parempi slide-järjestys Suomalaiselle:**
Hero → Ownership structure + anti-timeshare + exit → Costs & Revenue (läpinäkyvä) → Features → Balance sheet → Lifestyle close

## Q6 — Legal riskit

**Suurin tappaja. Nykyinen disclaimer täysin riittämätön.**

- EU Timeshare Directive 2008/122/EC: kieltää markkinoimasta investointina jos käyttöoikeus yli vuosi
- AIFMD: Jos rakenne muistuttaa kollektiivista sijoittamista → FIN-FSA-valtuutus tarvitaan
- Markkinointi "returns/scenarios/ROI" → FIN-FSA-tutkinta tai sopimuksen mitätöinti
- Yacht + VAT + rekisteröinti + charter-säännöt erikseen
- Raja myyntipresentaatio vs. finanssituote: jos esität taloudellisia ennusteita → olet finanssituotteen markkinoinnissa Suomessa

## Q7 — Skaala

Universaali ydin: Phase 0 lock + Kill Vector + compliance + läpinäkyvä talous + disclaimer + delivery

Asset-specific muutokset:
- Purjealukset/veneet: Crew/fuel/depreciation + merirekisteri + VAT-charter
- Loma-asunnot: Kaavoitus, yhtiömuoto, vuokratulot, kiinteistöverotus
- Kiinteistösyndikaatit: AIF-riski selkeämpi

## Q8 — Pivot-tunnistus Phase 0:ssa

Pakollinen Lock Checklist:
- [ ] Juridinen rakenne + lakimiehen ok
- [ ] Talousmalli ulkoisesti auditattu
- [ ] Management company nimetty + referenssit

- [ ] Kilpailija-vertailu tehty

Red flags = älä rakenna:
- Hinta/kulut muuttuvat vielä
- "Sovitaan juridiikasta myöhemmin"
- Ei nimettyä management companya
- Ostaja ei ole vielä vahvistettu
