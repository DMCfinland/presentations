# On-Page SEO Audit: Jarvisydan.com

**Audit Date:** 2026-02-11
**Auditor:** AI SEO Audit (Claude Code)
**Domain:** https://www.jarvisydan.com/en/
**Scope:** 5 key English-language pages

---

## Executive Summary

Hotel & Spa Resort Jarvisydan's website demonstrates a solid structural foundation with clean URL hierarchies, functional navigation, and comprehensive schema markup. However, the site suffers from **significant on-page SEO gaps** that are likely suppressing organic visibility for high-value English-language search queries.

**Critical issues** include missing meta descriptions on 4 of 5 audited pages, absent Open Graph tags across all pages, inconsistent image alt text optimization, and thin content on key conversion pages. The homepage title tag uses the generic prefix "Front page" instead of keyword-rich copy, wasting the single most important on-page ranking signal.

The site scores well on URL structure, internal linking architecture, and schema implementation. These structural strengths provide a strong base for rapid improvement once the content and metadata gaps are addressed.

## Prioritized Recommendations

### Phase 1: Quick Wins (1-2 Days, High Impact)

**1. Write unique meta descriptions for all pages**
- Homepage, Accommodation, and Restaurants are missing meta descriptions entirely
- Target 150-160 characters, include primary keyword + location + CTA
- Expected impact: 15-30% CTR improvement from SERPs

**2. Rewrite homepage title tag**
- Change from: "Front page - Hotel & Spa Resort Jarvisydan"
- Change to: "Hotel & Spa Resort Jarvisydan | Lake Saimaa, Finland"
- Expected impact: Improved ranking for brand + location queries

**3. Add location keywords to all title tags**
- Every title should include "Lake Saimaa" or "Finland"
- Pattern: "[Page Topic] | Jarvisydan, Lake Saimaa Finland"

**4. Fix the "Hearth" typo** on the Accommodation H1
- Change to "Heart of Lake Saimaa"

**5. Fix the `/accomodations/` URL** (add missing 'm' or implement redirect)

### Phase 2: Content & Image Optimization (1-2 Weeks)

**6. Add descriptive alt text to ALL images**
- Hero images on every page currently lack alt text
- Use format: "[descriptive keyword] at Jarvisydan, Lake Saimaa"
- Example: "Lakeside hotel rooms overlooking Lake Saimaa at Jarvisydan"
- Translate Finnish alt tags on English pages to English

**7. Expand Accommodation page content to 500+ words**
- Add overview descriptions for each accommodation type
- Include amenities, capacity, and seasonal availability
- Add location context (Lake Saimaa, Rantasalmi, distance from Savonlinna)

**8. Optimize H1 tags with target keywords**
- Homepage: "Nature Hotel & Spa Resort on Lake Saimaa"
- Accommodation: "Accommodation on Lake Saimaa, Finland"
- Restaurants: "Restaurants & Dining at Jarvisydan"
- Activities: "Activities & Nature Experiences on Lake Saimaa"

**9. Rename generic image files**
- `Image-282.jpg` -> `jarvisydan-lakeside-accommodation-saimaa.jpg`
- `Illallinen-tulikeittio.jpg` -> `fire-kitchen-dining-jarvisydan.jpg`
- Reupload with descriptive English filenames

### Phase 3: Technical & Structural (2-4 Weeks)

**10. Implement Open Graph tags on all pages**
- `og:title`, `og:description`, `og:image`, `og:url`, `og:type`
- Add Twitter Card meta tags
- Critical for social sharing and referral traffic

**11. Add explicit canonical tags**
- Self-referencing canonicals on every English page
- Implement proper hreflang tags linking EN/FI versions

**12. Fix `/en/spa/` redirect**
- Currently sends to holiday package page
- Should redirect to `/en/lakespa-dayspa/` or create proper spa landing page at `/en/spa/`

**13. Add H3 subheadings for content depth**
- Activities page: Group under category H2s (Yoga & Wellness, Nature Tours, Water Activities) with individual activities as H3s
- Accommodation page: Use H3s for room features and amenities

**14. Create content depth for Restaurant page**
- Expand each restaurant description to 80-100 words
- Add cuisine type, price range, seating capacity, seasonal availability
- Include local ingredient sourcing mentions for E-E-A-T

### Phase 4: Keyword Strategy (Ongoing)

**15. Integrate regional/location keywords across all pages**
- Primary: "Lake Saimaa", "Finland"
- Secondary: "Rantasalmi", "Savonlinna", "Eastern Finland", "Finnish Lakeland"
- Tertiary: "Linnansaari National Park", "Saimaa ringed seal"

**16. Add seasonal content sections**
- "Winter Activities at Jarvisydan" / "Summer Activities at Jarvisydan"
- Helps capture seasonal search intent peaks

**17. Expand long-tail keyword targeting**
- "Best spa hotel in Finland"
- "Lake Saimaa accommodation"
- "Things to do near Savonlinna"
- "Ecological spa Finland"
- "Award-winning restaurant Finnish Lakeland"
