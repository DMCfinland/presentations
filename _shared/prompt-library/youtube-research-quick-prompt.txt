## PHASE 0 MISSION

Run foundation research using parallel agents. We need answers to 4 independent research questions PLUS an Excel analysis. Launch agents in parallel where possible.

### STEP 1: Launch 3 research agents IN PARALLEL

**Agent 1 — "LLM Productivity Research"** (use Task tool, general-purpose agent, web search)
Research question: Does curated, high-quality research context actually boost LLM output quality?
- Search for evidence on RAG vs. no-RAG performance differences (2025-2026 studies)
- What's the difference between raw data dumps vs. curated insights as LLM context?
- At what point does more context become noise? What's the sweet spot?
- What formats does Claude handle best as context? (markdown vs. JSON vs. structured)
- What do power users of Claude/ChatGPT say about custom knowledge bases?
- Look for real benchmarks, not marketing claims
- Save findings to: YouTubeResearch-AIFiles/research-outputs/phase-0-llm-productivity.md

**Agent 2 — "Archive Format Research"** (use Task tool, general-purpose agent, web search)
Research question: What's the best format for archiving research so AI can retrieve and use it?
- Compare: plain markdown vs. YAML frontmatter + markdown vs. JSON vs. structured databases
- What file sizes work best for Claude context windows?
- How should cross-references work? (tags, links, indexes, knowledge graphs?)
- What makes content "mineable" vs. just "stored"?
- How do existing knowledge management systems (Obsidian, Notion, etc.) structure for AI retrieval?
- What's the simplest system that's still powerful?
- Save findings to: YouTubeResearch-AIFiles/research-outputs/phase-0-archive-formats.md

**Agent 3 — "YouTube Extraction + Batch API Research"** (use Task tool, general-purpose agent, web search)
Research TWO topics:

Topic A — YouTube transcript extraction:
- What tools exist? (yt-dlp, youtube-transcript-api, YouTube API v3, browser extensions)
- Quality: auto-generated vs. manual transcripts
- Rate limits and costs at scale (50-200 videos)
- Can Claude Code call these tools directly?

Topic B — Anthropic Batch API:
- Current pricing (should be 50% of standard API)
- How to submit batch jobs (API format, SDK usage)
- Turnaround time and size limits
- Best practices for batch prompt design
- Can we use it from Claude Code or need separate scripts?

Save findings to: YouTubeResearch-AIFiles/research-outputs/phase-0-extraction-and-batch.md
