## What It Does

A Claude Code skill that adds comprehensive SEO analysis commands. Install once, then use `/seo` commands directly in Claude Code.

## Key Commands

| Command | Description |
|---------|-------------|
| `/seo audit <url>` | Full website audit with parallel subagent delegation |
| `/seo page <url>` | Deep single-page analysis |
| `/seo technical <url>` | Technical SEO audit (8 categories) |
| `/seo content <url>` | E-E-A-T and content quality analysis |
| `/seo schema <url>` | Detect, validate, and generate Schema.org markup |
| `/seo images <url>` | Image optimization analysis |
| `/seo sitemap <url>` | Analyze or generate XML sitemaps |
| `/seo geo <url>` | AI Overviews / Generative Engine Optimization |
| `/seo plan <type>` | Strategic SEO planning (saas, local, ecommerce, publisher, agency) |
| `/seo programmatic <url>` | Programmatic SEO at scale |
| `/seo competitor-pages <url>` | "X vs Y" comparison page generator |
| `/seo hreflang <url>` | International SEO / hreflang audit |
