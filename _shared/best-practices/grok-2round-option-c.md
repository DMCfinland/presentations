When Grok Heavy Round 1 rejects all provided options (GO / NO GO on everything), the natural instinct is to re-argue A/B with new evidence. This is wrong.

**Rule:** Round 1 that rejects all options = run Round 2 explicitly asking "What IS the viable option?" with these changes:
1. Tell Grok explicitly: "Round 1 rejected A and B — treat this as established, do not re-litigate"
2. Frame as open-ended search: "What do teams actually use in 2025–2026 for this exact problem?"
3. Ask Harper to find real-world implementations, not textbook answers
4. Ask Benjamin to build actual cost model for whatever Option C emerges
5. Ask Lucas to challenge Option C with month-6 failure modes

**Why:** Grok optimizes for contrast and challenge in Round 1. It will surface risks you missed. But it won't spontaneously propose alternatives — you have to ask explicitly in a separate round.

**How to apply:** Any Grok Decision Debate where all options are rejected. Do NOT combine Round 1 + Round 2 into one prompt — keep them separate so Round 2 is genuinely fresh.

**Validated:** S115 — 3 architecture decisions (DB, automation engine, MVP order). Round 1 rejected all 6 options. Round 2 found viable Option C for all three.
