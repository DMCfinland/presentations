# Parallel Project Splitting

**What:** When a complex multi-stakeholder negotiation has independent tracks, split into separate project documents rather than one bundled proposal.

**Why:** Bundled proposals create single points of failure — if one track stalls, everything stalls. Independent tracks can proceed at their own pace, each with own go/no-go criteria.

**When to apply:** Any negotiation with 2+ distinct value streams that don't depend on each other for approval (e.g., infrastructure transfer + EU funding + service sales).

**Example:** Rantasalmi/Järvisydän — originally one 4-track bundle. Split into (1) infrastructure + service sales to municipality, (2) Leader EU funding direct to DMC. Each can succeed independently.
