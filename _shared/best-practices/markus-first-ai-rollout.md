**Rule:** Never launch an AI intelligence system to staff with "CEO dashboard" as the first visible use case.

**Why:** Panopticon Effect — if the first thing 50 employees see is a system that tracks what they say for the CEO, trust collapses. People stop using Teams/meetings for real conversations → system goes blind → project fails.

**The pattern:**
1. Start with the BUSIEST OPERATIONAL PERSON (e.g. Markus — entrepreneur-CEO, lots of meetings, info doesn't flow)
2. Frame as "Personal Memory Tool" not surveillance
3. Deliver via WhatsApp/email — NOT a dashboard. Busy people don't open dashboards.
4. Prove value privately: "Today you promised X to Y. Second Brain says that conflicts with contract Z."
5. When that person says "this saved my skin" — THEY become the system champion
6. THEN expand to management team (sleep-on-it decision gate)
7. THEN CEO portfolio dashboard — only after trust is established

**Finnish-specific framing for YT-menettely:**
- SAY: "Muistituki" (Memory Support), "Informaatioähkyn poisto"
- DON'T SAY: "Seuranta" (monitoring), "Tehokkuus" (efficiency), "Tallennus" (recording)

**Green/Yellow/Red traffic light for private digests (Gemini pattern):**
- Green (routine operations) → auto-forward after 4h
- Yellow (commitments, promises) → hold 24h, nudge once, then release with flag
- Red (personnel, salary, sensitive strategy) → hard gate, never auto-forward

**"Clean Hands" protocol:** If AI flags a problem, never reference the AI transcript directly in a confrontation. Use the knowledge to ask better questions. "How is Project X going?" not "The AI told me you said X."

**Why:** Gemini validated (2026-03-25). S111 transcript pipeline design.

**When to apply:** Any AI system that processes employee communications, meetings, or activity data — in any of the 10 portfolio companies.
