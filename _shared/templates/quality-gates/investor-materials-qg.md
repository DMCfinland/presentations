# Quality Gate: Investor Materials

Run this checklist before delivering ANY investor-facing document.

## Consistency Check
- [ ] Every number matches the single source of truth file
- [ ] Revenue figures are identical across deck, memo, and model
- [ ] Team bios and titles are consistent across all materials
- [ ] Use-of-funds percentages sum to 100%
- [ ] Milestone dates align across all documents
- [ ] Raise size and instrument are identical everywhere

## Credibility Check
- [ ] All claims are verifiable or labeled as estimates
- [ ] Market sizing has explicit assumptions (top-down AND bottom-up)
- [ ] No hype language ("revolutionary", "game-changing", "disruptive")
- [ ] Risks are mentioned, not hidden
- [ ] Competitor analysis is honest (not strawman)

## Arithmetic Check
- [ ] Revenue layers sum correctly
- [ ] Growth rates match year-over-year figures
- [ ] Use-of-funds breakdown sums to the raise amount
- [ ] Financial model inputs produce the stated outputs
- [ ] Margins are consistent between slides

## Audience Check
- [ ] The ask is specific (amount, instrument, timeline)
- [ ] The story is clear without prior context
- [ ] Assumptions are visible, not buried in footnotes
- [ ] Defensible in a partner meeting or board presentation
- [ ] Appropriate detail level (not too much, not too little)

## Finnish / Legal Context
- [ ] EUR currency used consistently (not USD unless specifically relevant)
- [ ] Finnish company law references correct (OYL for Oy, AbpL for Oyj)
- [ ] Tax implications noted where relevant (capital gains, dividend tax)
- [ ] Group structure diagram included if multiple entities involved
