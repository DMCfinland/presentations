# Quality Gate: Market Research

Run this checklist before delivering ANY research output.

## Source Quality
- [ ] Every important number has a source citation
- [ ] Sources are dated — stale data (>2 years) is flagged
- [ ] At least 2 independent sources for key claims
- [ ] Finnish-language sources included where market is Finnish
- [ ] No unsourced market size estimates

## Balance
- [ ] Contrarian evidence included (what argues against the thesis?)
- [ ] Risks and downsides are stated, not buried
- [ ] "We don't know" is stated where data is genuinely unavailable
- [ ] No confirmation bias (didn't just find evidence supporting the desired conclusion)

## Decision Orientation
- [ ] Executive summary leads with the answer, not the methodology
- [ ] Recommendation is specific and actionable
- [ ] Fact, inference, and recommendation are clearly separated
- [ ] "So what?" is answered for every finding
- [ ] The output makes a decision easier, not harder

## Privacy (GDPR)
- [ ] No company names or client names in web search queries (unless Patrick explicitly requested)
- [ ] No PII in the research output
- [ ] Competitor data from public sources only
- [ ] Financial data from published filings only (kaupparekisteri, PRH)

## Format
- [ ] Follows the standard output structure (Executive Summary → Findings → Risks → Recommendation → Sources)
- [ ] Board-ready format if intended for board presentation
- [ ] Cross-company applicability noted (does this apply to other portfolio companies?)
